# devops-plan-api

The backend for a 16-week DevOps learning plan. It stores the plan content, tracks my progress across devices, and collects proof of work for each task. I'm building it to learn backend design, and then I'll use it as the real app I containerize, deploy and monitor as part of the DevOps plan.

## Stack

- Node.js
- TypeScript
- Express (planned, arrives in M1)
- PostgreSQL (planned, arrives in M2)
- Knex (planned, arrives in M2)
- zod
- Vitest
